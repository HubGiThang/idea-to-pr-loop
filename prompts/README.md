# Prompts

Paste these into Claude. Replace everything in angle brackets first.

- `spec-and-mockup.md`: turns an idea into a spec and a clickable mockup for your design review, then cuts it into Linear issues once you approve.
- `get-started.md`: the starter prompt for a newcomer. Walks through the whole setup one step at a time and never asks for a password or token in the chat.
- `project-instructions.md`: the instructions to paste into a Claude project, one per product.
- `new-project.md`: the first message in a new Claude project for a new repo. Sets up the workflow and cuts the spec into issues.
- `build-locally.md`: builds one issue in Claude Code on your computer instead of in GitHub Actions, under the same branch and PR rules.
- `morning-sync.md`: a daily scheduled task. Updates each spec's status and the Overnight status callout in Notion.
- `weekly-retro.md`: a weekly scheduled task. Writes one Retros page from the week's PRs and reviews.

The two scheduled tasks need Claude with the Notion, Linear and GitHub connectors. Create them as scheduled tasks in the Claude app (or Claude Code on the web) and pick a time; the times below are only suggestions.
