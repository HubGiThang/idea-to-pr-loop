# Get started prompt

Paste this as the first message in a new Claude chat. It walks you through the setup one step at a time.

```
I want to set up the idea-to-pr-loop for my project. The template is at https://github.com/HubGiThang/idea-to-pr-loop.

Read its README.md and setup/README.md first. Then walk me through the setup one step at a time, in this order: Claude, GitHub, the Claude GitHub app and token, ChatGPT Codex review, Notion, Linear, Cloudflare, a Claude project with its instructions, adding the loop to my repo, the repo settings, and the two scheduled tasks.

For each step, explain in plain words what it does and why, tell me exactly what to click or run, and wait for me to say done before the next one. Never ask me to paste a password or token into this chat; I enter secrets in my own terminal.
```
